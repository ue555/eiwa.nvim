*eiwa.nvim*                              Native translation UI for Neovim

==============================================================================
INTRODUCTION                                                   *eiwa-intro*

eiwa.nvim provides a native Neovim conversation interface intended for
English-to-Japanese translation through an HTTP API. The asynchronous Go agent
connects to http://127.0.0.1:8000/translate by default. Start the API separately.

Requires Neovim 0.10 or later and LuaJIT 2.1.

==============================================================================
SETUP                                                           *eiwa-setup*

>
  require("eiwa").setup({
    command = nil,
    api = {
      endpoint = "http://127.0.0.1:8000/translate",
      timeout = 90,
      style = "source",
      glossary = {},
    },
    window = {
      position = "float",
      width = 0.8,
      height = 0.8,
      split_width = 0.4,
      split_height = 0.35,
      input_height = 3,
      border = "rounded",
    },
    history = {
      max_messages = 100,
    },
    keymaps = {
      submit = "<CR>",
      cancel = "<C-c>",
      close = "q",
    },
  })
<
window.position accepts "float", "right", "bottom", or "tab".
api.timeout is in seconds; api.style accepts "source", "polite", or "plain".
api.glossary maps English terms to Japanese translations. Restart Neovim after
changing settings. Complete translations appear after API generation finishes.
Cancellation stops HTTP waiting; server-side generation may continue briefly.

==============================================================================
COMMANDS                                                     *eiwa-commands*

:Eiwa             Toggle the Eiwa window.
:EiwaClose        Close the window while retaining session history.
:EiwaClear        Clear session history.
:EiwaCancel       Cancel the active request.
:EiwaNewSession   Cancel the active request and clear history.

==============================================================================
BACKEND                                                       *eiwa-backend*

Install a release binary, falling back to a local Go build:
>
  scripts/install-agent.sh
<
Build the Go backend for the current platform:
>
  scripts/build.sh
<
On Windows, use:
>
  powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
<
Build Linux amd64, Linux arm64, and Apple Silicon binaries:
>
  scripts/build.sh --all
<
The backend is resolved in this order:

1. The setup() command option.
2. eiwa-agent in $PATH.
3. bin/eiwa-agent-{os}-{arch} in the plugin.
4. bin/eiwa-agent in the plugin.
